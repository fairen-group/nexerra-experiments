# Nexerra Experiments

Prototype and supplementary workflows related to Nexerra-R1.

The production package is available at:

```text
https://github.com/fairen-group/nexerra-r1
```

This repository is intended for supporting prototype/experimental workflows.

## Layout

```text
src/nexerra_experiments/  reusable Python code
scripts/                  runnable scripts
notebooks/                exploratory notebooks
data/                     local experiment data
reports/                  notes and generated reports
artifacts/                local generated outputs
```
